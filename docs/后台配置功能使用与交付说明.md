# 日新辑览 · WebDAV 备份与 AI 补简介后台配置使用与交付说明

## 一、概述

本功能旨在为「日新辑览」开源自部署提供零门槛的配置体验。原先必须在 Cloudflare Pages 控制台填写的环境变量（WebDAV 与 Workers AI 凭证），现已完整搬入后台管理界面，实现**网页直填、即时生效、当场联调测试**，并在底层保持与既有环境变量配置 100% 兼容。

---

## 二、配置优先级与来源识别

系统严格遵循**环境变量优先、后台配置兜底**原则，后台卡片顶部设有实时状态徽标（Badge）：

| 状态徽标 | 说明 | 运行行为 |
| :--- | :--- | :--- |
| `环境变量（生效中）` | 探测到 Cloudflare Pages 中已配齐对应环境变量 | **环境变量管事**，业务逻辑完全走环境变量，后台即便修改了 KV 也不会生效（卡片内有提示，避免困惑） |
| `后台已配置（生效中）` | 环境变量未配置，但已在后台保存了有效配置 | **后台 KV 管事**，配置即时生效，无需重新部署 |
| `未配置` | 环境变量与后台 KV 均无有效配置 | 备份恢复接口返回 503 引导提示；AI 补简介平滑回退至网页抓取（保证功能永远可用） |

---

## 三、WebDAV 备份配置指南

在后台「肆 WebDAV 备份设置」卡片中进行管理：

### 1. 快捷预设
- **坚果云**：
  - 点击「坚果云」按钮自动填入地址：`https://dav.jianguoyun.com/dav/`
  - **特别注意**：密码处请填写坚果云网页端「账户信息 - 安全设置」中生成的**应用密码**（并非坚果云网页登录密码）；
  - 备份文件会自动写入对应目录下的 `rixin-jilan-backup.json`。
- **Nextcloud**：
  - 点击「Nextcloud」按钮填入模板：`https://你的域名/remote.php/dav/files/用户名/`；
  - 请将「你的域名」与「用户名」替换为您的实际服务信息。
- **自定义**：
  - 支持任意标准 WebDAV 服务，可填写目录或具体的 `.json` 文件全路径。

### 2. 即时测试与保存
- **测试连接**：点击后系统会发送标准 WebDAV `PROPFIND`（`Depth: 0`）探测连通性。若账号密码有误，会明确提示排查坚果云应用密码；
- **保存设置**：保存至 Cloudflare KV，即时生效；
- **清除配置**：提供安全清除按钮，确认后从 KV 中移除配置。

## 四、AI 补简介配置指南

在后台「伍 AI 补简介设置」卡片中进行管理，统一采用现网短语提示词（$\le 14$ 字短语、禁写完整句与句号）及超 20 字标点收尾修剪规范：

### 1. 支持的服务商及参数规范
| 服务商 | 协议类型 | 必填字段 | 推荐默认模型 / 说明 |
| :--- | :--- | :--- | :--- |
| **Cloudflare Workers AI** | 官方原生 API | 账户 ID（Account ID）、API 令牌（API Token） | `@cf/meta/llama-3.3-70b-instruct-fp8-fast` |
| **OpenAI** | OpenAI 兼容 | 接口地址（base_url）、API 密钥（api_key）、模型（model） | `gpt-4o-mini`（默认接口 `https://api.openai.com/v1`） |
| **Google Gemini** | OpenAI 兼容 | 接口地址、API 密钥、模型 | `gemini-2.5-flash`（官方兼容端点 `https://generativelanguage.googleapis.com/v1beta/openai/`） |
| **DeepSeek** | OpenAI 兼容 | 接口地址、API 密钥、模型 | `deepseek-chat`（默认接口 `https://api.deepseek.com/v1`） |
| **自定义** | OpenAI 兼容 | 接口地址、API 密钥、模型 | 支持任何兼容 OpenAI Chat Completions 规范的自建或第三方模型 |

### 2. 当场联调测试
- 点击「测试生成」按钮，系统会使用固定的测试样本（斗鱼直播 `https://www.douyu.com`）执行一次真实生成请求；
- 测试成功后，生成的中文简介结果会直接在卡片内展示，眼见为实；若上游服务报错，会标红展示错误摘要便于排查。

## 五、安全保密机制

1. **单向掩码回显**：
   - 接口与前端界面绝不回显密码或 API Key 的明文；
   - 仅返回掩码格式（如 `••••1234`，保留末 4 位），并仅作为输入框的 `placeholder` 提示，`value` 保持清空；
2. **留空不修改保护**：
   - 用户在修改配置时，若密码框留空，后端自动保留原存储在 KV 中的已有密码，避免误清空；
3. **接口严格鉴权**：
   - 所有 `/api/admin/config*` 接口统一经过 `requireAuth` 鉴权，仅允许已登录的管理员或持有有效 `ADMIN_API_TOKEN` 的机器令牌访问。

| 文件路径 | 模块类型 | 核心职能 |
| :--- | :--- | :--- |
| `functions/_lib/config.js` | 核心底层 | KV 存取（键名 `app_config`）、优先级裁决与掩码生成 |

| `functions/api/admin/config/test-ai.js` | 路由接口 | AI 生成真实样本联调测试 |
| `functions/api/admin/backup.js` | 业务接口 | 备份改走统一配置解析 |
| `functions/api/admin/restore.js` | 业务接口 | 恢复改走统一配置解析 |
| `functions/api/admin/ai-desc.js` | 业务接口 | 单站补简介接入统一配置与适配器，保持抓取兜底 |
| `functions/admin/index.js` | 前台交互 | 设置区块渲染、预设填入、动态表单显隐与测试反馈 |
