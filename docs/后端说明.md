# 后端接口规划（第二阶段）

形态对标 iori-nav：Pages Functions + D1（书签数据）+ KV（后台会话）。

## 接口

- `GET /api/sites` — 前台拉全量站点＋分类（私密条目不下发，除非带有效会话）
- `POST /admin/login` — 口令校验（环境变量 `ADMIN_PASSWORD`），成功后发 HttpOnly 会话 Cookie（KV 存 token，默认 7 天）
- `POST /admin/logout` — 注销会话
- `GET /api/admin/sites`、`POST /api/admin/sites`、`PUT /api/admin/sites/:id`、`DELETE /api/admin/sites/:id` — 书签增删改（需会话）
- `GET/POST/PUT/DELETE /api/admin/categories...` — 分类管理（含排序、私密）
- `POST /api/admin/import` — 书签 HTML / JSON 批量导入（复用前台导入器的解析口径）
- `GET /api/admin/export` — 导出 JSON / 浏览器书签 HTML

## 纪律

- 口令与密钥只走 CF 环境变量，永不进仓库。
- 前台在接口不可用时回退到 `data.js` 静态数据，网站永不白屏。
- 私密是「不下发」，不是前端藏起来——数据不出服务器才算私密。
